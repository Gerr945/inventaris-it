# Sistem Peminjaman Inventaris IT

Aplikasi peminjaman inventaris IT berbasis web yang dikembangkan menggunakan Laravel dan MySQL, dengan versi aplikasi mobile menggunakan Flutter.

## Fitur Utama
- Login pengguna dan admin
- Dashboard inventaris
- Pengajuan peminjaman barang
- Pengelolaan persetujuan peminjaman
- Pengembalian barang
- Pesan dan notifikasi
- Riwayat peminjaman

## Teknologi
- Laravel
- PHP
- MySQL
- HTML, CSS, JavaScript
- Flutter (aplikasi mobile)

## Tujuan
Proyek ini dibuat untuk mendukung pengelolaan peminjaman inventaris IT dan sebagai bagian dari kegiatan Praktik Kerja Lapangan (PKL).

## Catatan
Source code ini merupakan proyek pengembangan. Untuk menjalankan aplikasi, diperlukan konfigurasi lingkungan dan database tersendiri.
